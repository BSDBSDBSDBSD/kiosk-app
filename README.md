# Kiosk Launcher — אפליקציית קיוסק להשכרת מכשירים

אפליקציית מסך-בית (launcher) לאנדרואיד שמחליפה את ה-Home הרגיל, מציגה רק
אפליקציות שאתה מאשר, ומונעת יציאה ממנה בלי סיסמה. משתמשת ב-API הרשמי של
אנדרואיד ל-Kiosk/Device Owner, כשהרוט משמש רק כדי *להפעיל* את המצב הזה
פעם אחת.

## איך זה עובד

1. **MainActivity** — מסך הבית. מציג גריד של האפליקציות המותרות בלבד.
   לחיצה ארוכה (long-press) בפינה הימנית-תחתונה (בלתי-מסומנת) פותחת בקשת PIN.
2. **SettingsActivity** — נגיש רק אחרי PIN נכון. שם בוחרים אילו אפליקציות
   מותקנות יופיעו בקיוסק, ומשם גם משנים את הסיסמה.
3. **Device Owner + Lock Task Mode** — ברגע שהאפליקציה הופכת ל-"Device Owner"
   (ראה שלב ההפעלה למטה), היא יכולה:
   - לנעול את המכשיר לתוך עצמה בלבד (`startLockTask`) — חוסם Home, Recents.
   - לבטל את שורת ההתראות (`setStatusBarDisabled`).
   - לבטל את מסך הנעילה (`setKeyguardDisabled`) כך שאין דרך לעקוף אותה.
   - להגביל אילו אפליקציות מותר בכלל להריץ (`setLockTaskPackages`).

   כל זה הוא ה-API **הרשמי והנתמך** של גוגל לאפליקציות קיוסק (בשימוש בפועל
   ע"י חברות MDM כמו Kiosk Browser Lockdown, Hexnode וכו') — לא האק.

## שימוש ב-root

בדרך כלל הפיכת אפליקציה ל-Device Owner דורשת חיבור מחשב (`adb shell dpm
set-device-owner ...`) על מכשיר "נקי" (בלי חשבון גוגל מוגדר). **בזכות
ה-root אפשר להריץ את אותה פקודה ישירות מתוך האפליקציה עצמה**, בלי מחשב —
זה כל מה שהרוט נותן לנו כאן. אחרי הפעם הזו, כל האכיפה רצה דרך ה-API
הרגיל, ואין עוד תלות ברוט (אין risk של "עוקפים עם רוט" כי גם למשתמש עם
רוט אין דרך פשוטה לצאת מ-Lock Task Mode בלי הסיסמה של הקיוסק).

**חשוב:** `dpm set-device-owner` נכשל אם יש כבר חשבון Google מוגדר במכשיר,
או אם כבר יש Device Owner אחר. לפני ההפעלה — הסר חשבונות גוגל
(הגדרות ← חשבונות), ואז בתוך האפליקציה: הגדרות ← "הפעל נעילת קיוסק מלאה".

## בניית APK בלי להתקין כלום — דרך GitHub

הפרויקט כולל workflow מוכן (`.github/workflows/build-apk.yml`) שבונה APK
אוטומטית בענן בכל פעם שמעלים קוד. ככה לא צריך להתקין Android Studio.

1. פתח [github.com/new](https://github.com/new) וצור repository חדש
   (אפשר Private), למשל בשם `kiosk-app`.
2. העלה אליו את כל התוכן של התיקייה `kiosk-app` שקיבלת (גרירה בדף ה-repo,
   או `git push` אם אתה מכיר git).
3. עבור ללשונית **Actions** ב-repo — ה-build יתחיל אוטומטית (או לחץ
   "Run workflow" אם לא).
4. אחרי כ-2-3 דקות: היכנס ל-run שהסתיים ← גלול למטה ל-**Artifacts** ←
   הורד את `kiosk-app-debug-apk` (קובץ zip שמכיל את ה-APK בפנים).
5. חלץ את ה-zip, קבל את `app-debug.apk`, והעבר אותו למכשיר להתקנה.

## בניה מקומית (Android Studio) — חלופה

דורש [Android Studio](https://developer.android.com/studio) (חינמי).

```bash
# משכפלים/פותחים את התיקייה הזו ב-Android Studio, או בשורת פקודה:
cd kiosk-app
./gradlew assembleDebug
# ה-APK ייווצר תחת: app/build/outputs/apk/debug/app-debug.apk
adb install app/build/outputs/apk/debug/app-debug.apk
```

## הגדרה ראשונה במכשיר

1. התקן את ה-APK.
2. הסר כל חשבון Google מהמכשיר (Settings → Accounts).
3. פתח את Kiosk — יופיע מסך ריק ("לא נבחרו אפליקציות").
4. לחיצה ארוכה בפינה הימנית-תחתונה → קוד ברירת מחדל: **1234**.
5. במסך ההגדרות: בחר את האפליקציות שמותר להשתמש בהן, ולחץ
   **"הפעל נעילת קיוסק מלאה (דורש root)"**.
6. שנה מיד את קוד ה-PIN (**"שנה סיסמה"**) — אל תשאיר את ברירת המחדל!
7. לחץ **"שמור ונעל"**.

מרגע זה: המכשיר יעלה ישירות למסך הקיוסק, אי אפשר לצאת ל-Home/Recents,
ורק אפליקציות שבחרת ירוצו. היציאה היחידה — לחיצה ארוכה בפינה + PIN שלך,
ואז "שנה בחירת אפליקציות" בהגדרות (מה שגם מבטל זמנית את הנעילה עד שחוזרים
למסך הבית).

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `MainActivity.kt` | מסך הבית / גריד אפליקציות / long-press ל-PIN |
| `SettingsActivity.kt` | בחירת אפליקציות מותרות, שינוי PIN, הפעלת device-owner |
| `KioskManager.kt` | עטיפת DevicePolicyManager — Lock Task, Status Bar, Keyguard |
| `RootUtils.kt` | הרצת פקודת `dpm set-device-owner` דרך `su` (חד פעמי) |
| `KioskPrefs.kt` | שמירת PIN מוצפן (SHA-256) ורשימת אפליקציות מותרות |
| `AppRepository.kt` / `AppInfo.kt` | סריקת אפליקציות מותקנות במכשיר |
| `KioskDeviceAdminReceiver.kt` | ה-Receiver הנדרש ע"י אנדרואיד ל-Device Admin |

## הערות אבטחה

- ה-PIN נשמר כ-hash (SHA-256), לא בטקסט גלוי.
- ברירת המחדל היא `1234` — **שנה אותה מיד** בהפעלה הראשונה.
- אם תרצה, קל להוסיף הגבלת ניסיונות (lockout אחרי X ניסיונות שגויים) —
  לא נכלל כרגע כדי לשמור על הקוד פשוט; תגיד לי אם תרצה שאוסיף.
